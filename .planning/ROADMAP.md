# Roadmap

This roadmap formalizes the sequence of the IT Internship Training Program phases.

## Phase 1: Support Fundamentals (L1/L2)
*Focus: Identity, Access, and Ticketing.*
- Deploy Windows Server (Active Directory).
- Deploy Ubuntu Server (GLPI Ticketing).
- Goal: Students resolve basic Helpdesk tickets and manage AD users.

## Phase 2: Network & Security (L2/L3)
*Focus: Monitoring and Threat Detection.*
- Deploy Zabbix for network monitoring.
- Deploy Wazuh SIEM and OpenVAS.
- Goal: Students monitor logs, scan for vulnerabilities, and secure the pfSense edge.

## Phase 3: Advanced Automation (L3)
*Focus: Scripting and Patch Management.*
- Deploy WSUS for centralized patching.
- Introduce PowerShell and Python automation scripts.
- Goal: Students automate redundant tasks and manage server updates at scale.

## Phase 4: Capstone Project
*Focus: Simulated Enterprise Rollout.*
- Students are given a blank environment and must deploy a mini-enterprise from scratch based on a provided specification.
- Goal: Final presentation and technical review of their architecture.
