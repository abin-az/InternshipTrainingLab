# Testing Practices

*Because this is a documentation and curriculum repository, traditional Unit Testing (e.g., Jest, PyTest) is not applicable.*

**Verification:**
- Markdown files should be manually verified for rendering correctness on GitHub.
- Interactive HTML dashboards (`kanban.html`, `pitch.html`, `architecture.html`) must be tested in a modern web browser for responsive layout and CSS correctness.
- The `build_tools.py` script can be tested locally using Python 3.x.
