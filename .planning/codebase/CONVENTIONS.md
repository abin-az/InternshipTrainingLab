# Codebase Conventions

**Documentation Standards:**
- All markdown must follow GitHub Flavored Markdown (GFM).
- Critical information, warnings, and tips should be highlighted using GitHub Alert syntax (e.g., `> [!WARNING]`).
- Architecture diagrams should be written in Mermaid.js syntax inside markdown files, or crafted as interactive HTML.

**Web Development Standards:**
- HTML/CSS/JS must use modern "Glassmorphism" aesthetics (translucency, dark mode).
- Do not use TailwindCSS unless explicitly required. Use vanilla CSS with custom properties (`:root`).
- Use modern fonts like 'Inter', 'Outfit', or 'Roboto'.

**Curriculum Integrity:**
- All labs must strictly follow the `AGENTS.md` guidelines (e.g., no GNS3, strict 3-Phase structure).
